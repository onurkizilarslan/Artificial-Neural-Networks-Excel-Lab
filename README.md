## How to use
Download a workbook and open it in Microsoft Excel. Change editable parameters and follow step-by-step training, weight updates, error metrics and learning curves. The common teaching dataset is bipolar AND. English workbooks are independently arranged teaching editions, using the same learning rules; their sheet layout and epoch counts can differ from the Turkish originals.

## Technical notes
- **ADALINE:** trains on continuous linear residuals using the online Widrow–Hoff (LMS) rule.
- **Perceptron:** updates weights on misclassified samples.
- Online mean squared error and classification mistake counts measure different objectives and should not be directly compared as equal scales.
